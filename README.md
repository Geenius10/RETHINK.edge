# MentalEdge V17 – Skill Mechanics

Basis: funktionierende V16.

Geändert statt angehängt:
- Cue-Auswahl innerhalb von Übungen entfernt. Ein Trainingsblock hat genau einen Cue.
- Übungen rotieren innerhalb eines Schwerpunkts, statt an mehreren Tagen dieselbe Aufgabe zu zeigen.
- Eigene Mechaniken: Reiz-Zoom (Fokus), entschlossene Entscheidung (Selbstvertrauen), Körperkarte/Regulation (Ruhe & Druck), Reset-Sequenzen, Routine-Reihenfolge (Vorbereitung).
- Bestehende Quiz-, Filter-, Imagery-, Reset- und Routineübungen bleiben als weitere Mechaniken erhalten.
- Blockstufe steuert Schwierigkeit; Sessions innerhalb einer Stufe wechseln die Trainingsform.
- Cue kann nur zentral angepasst werden und bleibt danach im gesamten Block konstant.
- Zoom auf iOS/PWA/Textastic zusätzlich unterbunden.
